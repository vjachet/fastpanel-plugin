# Доступы к панели (общее для всех инструментов fastpanel)

Все инструменты плагина читают один файл: `~/.config/fastpanel/config.json`, режим `600`,
каталог `700`. Путь переопределяется переменной `FASTPANEL_CONFIG`.

```json
{
  "url": "panel.example.com",
  "insecure": false,
  "accounts": [
    {"login": "user1", "password": "...", "label": "рабочий"},
    {"login": "user2", "password": "...", "name": "second", "url": "panel2.example.com"}
  ]
}
```

- `url` — хост панели; достаточно хоста, `https://` подставляется сам, суффикс `/api`
  инструменты добавляют одинаково для любой панели. Нестандартный порт — в хосте
  (`panel.example.com:8888`). Полный URL и лишний `/api` на конце тоже принимаются.
- `insecure: true` — только при самоподписанном сертификате панели.
- Имя аккаунта = `name`, если задано, иначе логин. `--account` принимает и то, и другое.
- Аккаунту можно задать свой `url` — это перебивает общий.

## Правила обращения с паролем

**Пароль панели не появляется ни в аргументах команд, ни в выводе, ни в переписке.**
Скрипты читают его сами и отдают только на `/login` самой панели.

- Скрипт откажется работать, если права шире `600` или файл принадлежит не тебе.
- Токен кешируется в `~/.cache/fastpanel/token-<аккаунт>` (`600`) и переиспользуется, пока
  жив; пароль трогается только когда токен протух. При 401 — один автоматический перелогин.
- Любая ошибка проходит через скрабер: значение пароля заменяется на `***`.

**Агенту нельзя выполнять `cat`, `grep`, `head`, `echo` по файлам в `~/.config/fastpanel/`
и просить пользователя продиктовать пароль.** Если файла нет, скрипт сам печатает готовую
инструкцию: путь, команды создания и пример содержимого — покажи её целиком и остановись.

## Выбор аккаунта

1. `--account ИМЯ` или переменная `FASTPANEL_ACCOUNT` (совпадение по `name` или логину).
2. Аккаунт один — берётся он.
3. Несколько и у одного `"name": "default"` — берётся он.
4. Иначе скрипт не угадывает: печатает список имён и просит выбрать. Спроси пользователя,
   молча не выбирай.
